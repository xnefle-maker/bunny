ALBERIA — Explore Mode Update

1) Extract this folder.
2) Open the ALBERIA-Sakura folder in VS Code.
3) Run index.html with Live Server.

This update adds:
- A locked first-screen entry state with a polygonal pink 'شروع کاوش' button.
- Scroll unlock and smooth movement to the featured games section after the button is clicked.
- A darkened, blurred presentation of the approved background after entering Explore mode. The background asset itself is not edited.
- A continuously moving polygon-framed featured games carousel populated from the existing ALL_GAMES database.
- Pause on hover/focus/touch and previous/next direction controls.
- The existing Popular Games section remains directly below the featured carousel.

The approved background is packaged at images/alberia-approved-background.png and was copied byte-for-byte from the user's approved IMG_4204.PNG.
